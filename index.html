I also build the tools I use

Beyond using Riverpod, Bloc and Provider, I've created my own state management and published it for other Flutter developers on pub.dev.

Published on pub.dev · MIT licensed

Firelive

A lightweight, real-time state manager for Firebase Firestore. Your lists update live on screen the moment the data changes, with no heavy state management library needed.

  • Real-time Firestore collection updates, built on Flutter's own ValueNotifier
  • Two versions: a full one with loading, error and pause/resume, and a lite one for maximum speed
  • Works on Android, iOS, macOS, web and Windows
  • A few lines of code to go from a database collection to a live list
FlutterFirebaseOpen sourceDart
View on pub.devGitHub
// Listen to a live collection
final users = FirestoreLiveListV1<UserModel>(
  path: 'users',
  fromMap: (data, id) => UserModel.fromMap(data, id),
);
await users.listen();

// Show it, and it updates itself
ValueListenableBuilder(
  valueListenable: users.notifier,
  builder: (_, list, __) => UserList(list),
);

Add it with firelive: ^0.0.1 in your pubspec.
